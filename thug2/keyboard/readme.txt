installation steps:

1. optionally back up your THUG2 installation, or at least the Game/Data directory, as this overwrites files directly
2. extract the zip
3. copy-paste the Game folder in the unzipped folder over your THUG2's Game folder
4. launch the game, enjoy the onscreen keyboard

partymod patches this file at runtime, but there are trivial changes between the prx packed version and the file on disk, so it doesn't currently work in combination with other game mods that blank the qb_scripts.prx file.
